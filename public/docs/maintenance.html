Maintenance

Maintainer Guide

Release Checklist

  • Run typecheck, lint, tests, and build.
  • Verify the demo in external Chrome.
  • Confirm Debug shows Mesh: updated when a face is detected.
  • Update the changelog.
  • Push to main and check the Pages deployment.

Asset Policy

Every runtime asset in public should keep source and license notes. The demo depends on the MediaPipe task model, canonical face OBJ, WASM runtime, and classic worker.

Debug States

Mesh: no-landmarks means no face landmarks are available. Mesh: updated means the 3D face mesh is actively driven by landmarks.
