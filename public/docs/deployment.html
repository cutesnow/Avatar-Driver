Deployment

GitHub Pages

The demo is published at the repository root on GitHub Pages: https://cutesnow.github.io/Avatar-Driver/

Settings

In GitHub, choose Settings, Pages, Build and deployment, then select GitHub Actions as the source.

Workflow

The deployment workflow installs dependencies, runs typecheck, lint, tests, builds the Vite app, and deploys dist.

Base Path

The Vite base path is /Avatar-Driver/. Keep this aligned with the repository name.
