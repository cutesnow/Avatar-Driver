Architecture

Browser-Local Face Driving

The app requests webcam access only after the user clicks Start Camera. Video frames are converted to ImageBitmap objects and sent to a classic Web Worker that runs MediaPipe Face Landmarker.

Runtime Flow

  1. Camera stream attaches to the video element.
  2. The frame loop samples video at the target FPS.
  3. The worker runs landmark, blendshape, and head pose detection.
  4. Results are normalized into the shared expression store.
  5. The Three.js render loop updates the face mesh from landmarks.

Mesh Mapping

MediaPipe can return 478 landmarks. The canonical face mesh has 468 vertices, so the renderer uses the first 468 landmarks and ignores the extra eye landmarks.

Static Runtime

Model, WASM, worker, docs, and demo assets live under public and are copied into dist by Vite.
